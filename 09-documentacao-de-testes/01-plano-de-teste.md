# 📦 4️⃣ Entregáveis Principais

O principal entregável do projeto são os **relatórios de defeitos (bug reports)**.

---

## 📝 Como criar um Bug no Azure DevOps

1. Acessar o projeto  
2. Clicar no botão "+"  
3. Selecionar "Bug"  

---

## 📌 Regras para criação de Bug Report

1. O título deve seguir o formato:

```
Seção → Descrição
```

2. Incluir os passos para reprodução  
3. Informar:

- Resultado esperado  
- Resultado atual  

4. Referenciar evidências:

- Requisitos (Confluence)  
- Design (Figma)  

5. Definir prioridade e severidade  

6. Atividade → Testing  

7. Adicionar screenshot completo com destaque  

8. Atribuir ao responsável (QA Lead)

---

# 🔄 5️⃣ Gestão de Defeitos e Ciclo de Vida

O processo de reporte de defeitos segue o fluxo:

1. Explorar a funcionalidade (timeboxing de 1 hora)  
2. Verificar se o bug já foi reportado  
3. Caso não seja duplicado, registrar no Azure DevOps  
4. Aguardar feedback do QA Lead  
5. Ajustar o bug report, se necessário
